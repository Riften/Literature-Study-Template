文献调研 Workspace

面向 code agent（Claude Code / Codex / DeepSeek 等）的科研文献调研模板项目。 每一次调研任务对应下方列表中的一条记录，点开即可查看该任务的总结页面。

给 code agent 的提示 在开始一次新的调研任务之前，请先阅读根目录的 AGENTS.md 与 docs/ 下的说明文档， 了解页面格式、引用工具、3D 可视化和文件命名约定。
